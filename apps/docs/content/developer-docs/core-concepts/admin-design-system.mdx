# Admin design system (Proofly look)

The admin follows the Figma file "Vextro admin" (Foundations and Components pages). The tokens
live in `packages/ui/src/styles.css`; only the admin imports that file, so the storefront is not
affected. Variable names match the Figma code syntax (`var(--key-top)`, `var(--raised)`).

## Rules

- **One blue.** `--primary` (#3F72DC light, #7FA2F5 dark) with opacity tints only (`--primary-soft`).
  `--action` is the same blue. A member's own accent pick still overrides `--primary*` at runtime.
- **Fonts.** DM Sans for every UI string. Bricolage Grotesque only for page titles and big
  numbers: the `text-page-title`, `text-stat` and `text-kit-stat*` utilities switch to it.
  Both load through `next/font/google` in `app/layout.tsx`.
- **Layers.** Shell (`--sidebar`, top bar) below the content panel (`--background`) below cards
  (`--card`) below raised surfaces (`--raised`: menus, toasts, floating bars). Dark mode is
  layered the same way, never flat black.
- **Key material** (gradient, top highlight, bottom lip, soft glow) is for the one primary action
  on a screen and main header actions only. Use `<Button>` (key-primary, the default variant) or
  `<Button variant="key-neutral">`. Everything small is `outline` (plain-outline) or `ghost`
  (plain-ghost). `loading` shows the spinner and blocks presses.
- **Status chips** (`components/layout/status-chip.tsx`) are coloured only when someone has to
  act; done states are neutral grey with a hairline.
- **Radius.** 16 for the content panel, 12 for cards, 10 for controls, 8 for chips.

## siteConfig

`packages/config/src/site.ts` (import `@commerce/config/site`) holds the platform name, tagline,
domain, logos, support contact, public URLs, locale defaults (INR, en-IN, Asia/Kolkata), UI
defaults (rows per page 10/25/50/100, toast times), plan-limit placeholders and social links. It
is pure data with no secrets, so client code may import it. The `site-config` sweep fails on the
literal brand name anywhere else.

## Routes

`apps/admin/src/lib/routes.ts` is the one list of admin URLs (`routes.orders.detail(id)`,
`routes.settings.taxes()`). Navigation data, the command palette and the shell read from it. The
`admin-routes` sweep fails on a new hardcoded admin href; the allow-list counts per file and may
only go down.

## Final theme tokens, dropdowns and glass

Values come from the Figma "Vextro" variable collection (Proofly light / dark).

- **Dark layers.** Shell `#0B0C0E` (`--sidebar`) < content panel `#101114` (`--background`, edge
  `--panel-border` white 6%) < card `#16171B` (gradient `--card-top` `#18191D` to `--card-bottom`
  `#16171B`) < raised / popover `#1C1D22`. Small cool-tinted steps, never flat black. Inputs use
  `--input-surface` (`#121316` dark, a step below the card; white light). Text is off-white:
  `--foreground` `#E6E7EA`, headings `--ink-strong` `#F5F6F8`, `--muted-foreground` `#9AA0AB`,
  `--muted-foreground-soft` `#858B95`; all clear WCAG AA on panel, card and popover.
- **Dark lines.** One white-alpha scale on every layer: rows `--line-list` 5%, `--line` and
  `--hairline` 6%, card edge `--border-soft` 7%, `--border` 9%, `--input` 10%, `--border-strong` 15%.
- **Card recipe.** The `surface-card` utility (gradient, hairline, `--shadow-card`) is used by
  `Card`, stat tiles, table cards and page states. Light is `0 1px 2px` + `0 4px 12px` at 6% / 4%;
  dark is the hairline, a white 4% top highlight and a 1px contact shadow (no deep black spread).
  Never on floating layers.
- **Dark key.** The primary key is a deep well of the accent with pale ink (default `#2F416B` to
  `#243459`, `#45598A` rim, `#E2EBFF` ink, a soft 22% glow), the twin of light's pale key with deep
  ink. `darkKey()` in `@commerce/core/admin-accent` derives it for any picked accent, and the
  stylesheet's `.dark` values are its output for the default blue (a test keeps them in sync).
- **Dark status tones.** Lifted hues on low-alpha fills: success `#5CC68C`, warning `#F0B65A`,
  danger `#F0756F`, info `#8FB0F7` at 10 to 12%. Solid fills (`bg-destructive`, `bg-success`)
  carry dark ink (`--*-foreground`), never white on a light tone.
- **Pictures.** Product thumbnails and media tiles sit on `--media` / `--media-tile` (white light,
  a soft `#DFE1E6` in dark): catalogue photos are cut for a light ground, and a black product on a
  transparent PNG disappears on a dark card.
- **Avatars.** Initials discs use `--avatar` / `--avatar-foreground` (ink in light; the accent's
  tint with its pale ink in dark, rather than a bright white disc).
- **Scrollbars and selection.** `--scrollbar-thumb` (white 16% in dark); dark text selection is
  the accent at 32%.
- **Banners.** Next-step and info banners use `surface-banner`: card surface, `--brand-border`
  and a left-to-right `--brand-wash` to `--brand-wash-end`. Never a solid navy.
- **Neutral chip.** `--chip-neutral` fill with `--chip-neutral-text` (dark `#23252B` / `#B4B9C2`).
- **Selected options.** `--brand-select` plus a primary border (stat tiles, option cards).
- **Dropdowns** (select, combobox, dropdown menu, popover, command): trigger `h-9` (compact `h-8`),
  8px radius, input surface and border, chevron that turns when open, 2px brand focus ring,
  `aria-invalid` red border. Menu is a glass popover with a 12px radius, `p-1.5`, max height
  20rem; rows are `2.125rem`, highlighted is brand 8%, selected is brand text with the check on
  the right. Motion is `motion-menu`: 150ms fade and 4px rise, none under reduced motion.
- **Glass** (floating layers only): utilities `glass-bar` (top bar once the page scrolls, floating
  bars), `glass-popover` (menus, popovers, ⌘K, toasts) and `glass-scrim` (dialog and sheet
  backdrops). Tokens: `--glass-bar`, `--glass-popover`, `--glass-border`, `--glass-highlight`,
  `--glass-scrim`. Without `backdrop-filter`, or with reduced transparency, they fall back to the
  solid `--raised` / `--popover` surface.
