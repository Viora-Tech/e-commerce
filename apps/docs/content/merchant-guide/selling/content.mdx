# Content types

A **content type** is your own kind of content, with the fields you choose. A size guide has a
title and size rows. An FAQ has a question and an answer. A store location has an address and
opening hours.

Each item you fill in is an **entry**. "Size guide" is the content type; "Women's tops" and
"Kids' shoes" are two of its entries.

You find them in **Content → Content types**.

## What this is for

- Write a size chart, an FAQ or your shop's address **once** and show it on many pages.
- Change it in one place, and every page that shows it changes too.
- Keep things tidy: every entry has the same fields, so nothing is forgotten.

## Make a content type

1. Go to **Content → Content types** and select **Add content type**.
2. **What do you want to make?** Pick a card:

   | Card | Comes with |
   | --- | --- |
   | **Size guide** | Title, Measured in (cm or inches), Sizes (one row per size: Size, Chest, Waist, Length), How to measure, Picture |
   | **FAQ** | Question, Answer, Topic |
   | **Team member** | Name, Role, Photo, About them, Instagram link |
   | **Store location** | Store name, Address, City, Phone number, Opening hours, Google Maps link, Photo |
   | **Testimonial** | Customer name, What they said, Stars, Photo, Product they bought |
   | **Lookbook** | Title, Cover picture, Photos, Products in the look, Story |
   | **Start from blank** | Nothing yet. You add every field yourself. |

3. **What should we call it?** Keep the name or type your own, for example "Kurta sizes".
4. Select **Create**. The form for your first entry opens straight away.

You can change the fields later with **Edit fields** on the content type's page.

## Walkthrough: a size guide

1. **Content → Content types → Add content type**, pick **Size guide**, select **Create**.
2. Fill in the first entry:
   - **Title**: Women's kurtas
   - **Measured in**: inches
   - **Sizes**: select **Add row** and fill in one size per row, for example Size `S`, Chest
     `36`, Waist `30`, Length `40`. Use the arrows to change the order, the bin to remove a row.
   - **How to measure**: "Measure around the fullest part of your chest."
   - **Picture**: pick a measuring diagram from your files (upload it first under
     **Content → Files**).
3. Select **Save**. Make one entry for each chart you need, like Men's shirts or Kids' wear.
4. To show it on your store, go to **Online Store → Themes** and select **Customize**. Open the
   product template, select a section, and next to a text setting select the small database
   button, **Connect dynamic source**. Pick **Size guide → Women's kurtas** and the field you
   want, for example **How to measure**. See [Online store](./online-store) for more on
   connecting settings.

<Callout type="info">
  **Tip.** Want to start a new chart from an old one? Open the entry and select **Duplicate**.
  The copy is saved as a **Draft**, so it stays hidden until you change it to **Active**.
</Callout>

## Kinds of fields

When you add a field yourself, you choose **What goes in it**:

| Choice | Use it for |
| --- | --- |
| **Short text** | A name, a label, or one of a few choices (add **Preset choices** for a list to pick from). |
| **Long text** | Plain text over several lines, like care instructions. |
| **Formatted text** | Text with headings, bold, lists and links. |
| **Whole number** | Numbers like 12 (warranty in months). |
| **Decimal number** | Numbers like 1.5 (weight in kg). |
| **Money** | An amount, like ₹499. Type rupees; we keep the exact paise. Pick another currency under **Limits** if you need dollars or euros. |
| **Star rating** | Stars to tap, out of 5 (or 10 under **Limits**). Tap the fourth star for 4 stars, **Clear** to remove them. |
| **Measurement** | A number with a unit, like 1.5 kg or 30 cm. Under **Limits**, pick whether it measures weight, length or volume. |
| **Pick from a list** | Choices you write, one per line (S, M, L). Turn on **Allow several values** to tick more than one. |
| **Yes / No** | A tick box. |
| **Date** | A day on the calendar. |
| **Date and time** | A day and a time, like when a sale starts. Times are in your store's time zone. |
| **Colour** | A colour: tap the square to pick one, or type a code like `#1A2B3C`. |
| **Link** | A web address starting with `https://`. |
| **Button link** | The words on a button and where it goes, a web address or one of your pages like `/pages/size-chart`. |
| **File** | A picture or document from **Content → Files**. |
| **Product** / **Product variant** / **Collection** | One of your products, one size or colour of a product, or a collection. |
| **Page** / **Blog post** | One of your pages or blog posts. |
| **Another entry** | An entry of another content type, like linking a testimonial to a team member. |
| **Rows of fields** | A small table you fill row by row, like one row per size. You choose the fields each row has (up to 12), like Size, Chest and Waist. |

Turn on **Allow several values** to keep a list, like several products or several colours.
Turn on **Must fill** if an entry cannot be saved without it.

<Callout type="info">
  **Once entries use a field, what goes in it is fixed.** You can still rename it, change its
  limits or its choices, and add or remove the fields of its rows. To change the kind of value,
  add a new field, or clear the old one in every entry first.
</Callout>

## Extra fields on products and collections

**Extra fields** add your own fields to every product or collection, like a care guide or a
warranty period. Set them up in **Settings → Custom data**, then fill them in on each product's
**Extra fields** card.

## Draft or Active

Each entry has a **Status**. **Draft** entries stay hidden from your store; **Active** entries
can be shown. Use Draft while you are still writing.

## Common problems and fixes

| Problem | Why it happens | Fix |
| --- | --- | --- |
| "Fix the fields marked in red, then save again" | A field that must be filled is empty, or a value doesn't fit (for example letters in a whole number). | Read the red message under each field and change it. |
| "needs a date, like 2026-01-31" | The date isn't a real calendar day. | Pick the date from the calendar. |
| "must be picked from the choices" | **Measured in** (or another **Pick from a list** field) only accepts its own choices. | Pick one from the list. |
| "... already has values in 3 entries, so what goes in it cannot change" | Entries use that field, and their values were saved as its old kind. | Add a new field instead, or clear the field in those entries first. |
| "Sizes row 2: Size is required" | A row of a **Rows of fields** field has an empty field that must be filled. | Fill it in, or remove the row with the bin. |
| "needs a unit" | A **Measurement** has a number but no unit. | Pick the unit next to the number. |
| "needs a date and a time" | The **Date and time** field has only part of it. | Pick both the day and the time. |
| "links to an entry that was deleted. Pick another one" | The entry you linked to was deleted. | Pick another entry, or clear the field. |
| "Still used by ... Remove those fields first" | Another content type or an extra field links to the one you want to delete. | Remove that field first, then delete. |
| "The handle cannot change once the content type has entries" | Your theme finds entries by the handle, so it is fixed after the first entry. | Keep the handle, or make a new content type. |
| I don't see the **Add content type** button | Your staff role cannot change content. | Ask the store owner to give your role the content permission. |

## FAQ

<Faq>

<FaqItem question="Do customers see the content type's name?">

No. The name is for you and your staff. Customers only see the entries your theme shows.

</FaqItem>

<FaqItem question="Can I use the admin in Hindi?">

Yes. Pick **हिंदी (Hindi)** under **Account → Admin language** (the account menu, top right). Every content type screen is in
Hindi. The ready-made field names (like "Sizes") stay as they were created, and you
can rename them in **Edit fields**.

</FaqItem>

<FaqItem question="I picked the wrong card. Can I change it?">

Yes. Open the content type, select **Edit fields**, and add, rename or remove fields. If it has
no entries yet, you can also delete it and start again.

</FaqItem>

</Faq>
