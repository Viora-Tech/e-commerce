# Discounts

Go to **Discounts** in the sidebar. The list shows every discount with its value, how many
times it was used and the dates it runs. Select **Create discount** to make a new one.

## Two kinds of discount

- **Discount code.** Shoppers type a code, such as `DIWALI10`, in the cart or at checkout.
  Case does not matter: `diwali10` works too.
- **Automatic.** Applied to every cart that qualifies, no code needed. When several automatic
  offers fit a cart, the one that saves the shopper the most wins.

## What it gives

| Choice | What the shopper gets |
| --- | --- |
| **Percentage off** | A share of the price, for example 10% off. |
| **Fixed amount off** | A rupee amount, for example ₹200 off. Taken once from the order, never more than the items it covers are worth. |
| **Free shipping** | Shipping is free on the order. |

## What it applies to

- **Entire order**: every product in the cart.
- **Specific products**: only the products you pick. Search, tick the products, and they are
  listed above the search box. Select the cross on a row to take a product off.

## A different amount for each product

One code can take a different amount off different products. For example, the code
`KILLTONED` takes ₹200 off a keyboard and ₹300 off a mouse.

1. Under **Applies to**, choose **Specific products** and pick the products.
2. Turn on **Different amount for each product**.
3. Type an amount next to each product. With **Percentage off** each box takes a percentage
   (up to 100%); with **Fixed amount off** each box takes rupees.
4. Select **Save**.

The amount comes off **every piece** of that product. Two keyboards with ₹200 off each means
₹400 off. A fixed amount never takes more than the product's price, so a ₹500 discount on a
₹300 product gives ₹300 off. Products in the cart that are not on the list get nothing off,
and a cart with none of the listed products is told the code does not apply to its items.

Every product on the list needs an amount above zero before you can save. The **Value**
column on the discount list shows the range, for example "₹200 to ₹300 off each item".

The minimum order amount, usage limits and dates work the same way as for any other discount.

## Minimum, limits and dates

- **Minimum requirement**: the cart must be worth at least this much before the discount.
- **Usage limits**: cap the total number of uses, or allow one use per customer (counted by
  email address).
- **Active dates**: when the discount starts, and optionally when it ends.

The order keeps the discount's name, code and the rupee amount it took off, so later changes
to the discount never change an order already placed.

## Turning a discount off

Set **Status** to **Disabled** to stop it working while keeping it for your records. Deleting a
discount that was already used on orders disables it instead, so order history stays intact.
