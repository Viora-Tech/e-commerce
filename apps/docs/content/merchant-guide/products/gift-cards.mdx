# Gift cards

## What this is for

A gift card is a code with a rupee balance that anyone holding it can spend at checkout. Use it
to sell gifts ("₹2,000 gift card for my brother"), or issue one by hand for a giveaway or a thank
you. Shoppers spend it at checkout alongside UPI, cards or cash on delivery; whatever the card
does not cover, they pay the usual way.

Gift cards are not the same as **store credit**. Store credit is a balance on one customer's
account (for refunds and returns), with no code to share. See
[Customers: store credit](/merchant-guide/customers/customers).

## How it works

- **Products → Gift cards** lists every card with its status, balance, customer, how it was made
  (**Bought at checkout** or **Issued manually**) and the date. The cards on top show **Active
  gift cards** and **Outstanding balance**, the money still **owed to customers** on cards.
- A card sold on your store is a **gift card product**: one variant per denomination. When the
  payment clears, the code is emailed to the buyer.
- The code is shown **once**, when the card is made. After that you only see its last four
  characters, so a code cannot leak from your admin.
- Each use at checkout, refund to the card and balance change is in the card's **Activity**.
- Codes are stored encrypted.

## Sell gift cards on your store

<Steps>

### Add the product

Select **Add gift card product**. Give it a name and type the **Denominations** (press Enter after
each, for example 500, 1000, 2000). Select **Create product**.

### Finish and publish

It starts as a draft, so you can add a picture and description first. Publish it like any
product; add it to a menu or collection so shoppers find it.

### Set expiry

Under **Expiration**, choose whether sold cards **Never expire** or expire after a period. Cards
you issue by hand take the date you pick.

</Steps>

## Issue a gift card by hand

1. Select **Create gift card**.
2. Leave **Gift card code** empty to generate one, or type your own.
3. Enter the **Initial value** and, if you want, an **Expiration date**.
4. Pick a **Customer** (the card shows on their page), **or send to an email address** with a
   recipient name and a message printed in the email.
5. Tick **Email the gift card code now** to send it through your email channel.
6. Add an **Internal note** if you like, then select **Create gift card**.
7. **Copy the code now**: it is never shown again.

## Look after a card

Open a card to:

- **Adjust balance**: add or remove money, with a note (for example "goodwill after a late
  delivery"). Every change is kept in the history.
- Set or remove its **Expiration date** and **Usage limit** (how many checkouts may spend it).
- **Disable** it: a disabled card cannot be used at checkout; enable it again any time.
- **Resend** the code to its recipient or customer.

<Callout>
  A refund to a gift card puts the money back on the same card (**Refunded to card**), so the
  customer can spend it again.
</Callout>

## Common problems and fixes

| Problem | Fix |
| --- | --- |
| I lost a code | It cannot be shown again. Disable the card and issue a new one with the same balance |
| The buyer did not get the email | Open the card and resend it; check their email address and **Settings → Notifications** |
| A shopper says the code does not work | Check the card is active, not expired, has balance left and is under its usage limit |
