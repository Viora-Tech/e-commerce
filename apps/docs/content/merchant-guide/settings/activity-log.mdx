# Activity log

**Settings → Activity log** lists every change made to your store: who made it, when, and from
where. Use it to answer questions like "who created this shipping zone?" or "who changed this
product's price?".

Only changes are recorded. Opening a page or reading a report is not.

## What each row shows

- **When**: how long ago the change was made. Select it to open the details.
- **Who**: the person's name and email. A change made by an AI app or an access token shows the
  person it acts for.
- **What**: one line, such as *Shipping zones: create · Kinja*.
- **Area**: Products, Orders, Settings and so on.
- **From**: where the change came from: **Admin**, **AI assistant**, **AI app (MCP)** or **API token**.

## See the details of a change

Select a row's time or its **What** line. A window opens with:

- the action and the record it changed;
- the IP address and browser it came from;
- **What changed**. For some changes, such as editing a shipping zone, this is a table with each
  changed field **Before** and **After**. For the rest, it shows the values that were sent.

Payment keys, passwords, access tokens, sign-in codes and customers' contact details are never
stored. Where one was part of a change, it shows as `[redacted]`.

## Find a change

Select the filter button to narrow the list by:

- **Person**: one member of your team.
- **Area**: Products, Orders, Settings and so on.
- **From**: Admin, AI assistant, AI app (MCP) or API token.
- **Date**: the last 7, 30 or 90 days, or your own range.

Type in the search box to find changes by their description or action name, such as *Kinja* or
*shipping*.

## Who can see it

The store owner and the **Administrator** role see the activity log. To give it to another role,
open **Settings → Staff → Roles**, edit the role and turn on **Activity log**.

## How long changes are kept

Changes are kept for **one year**, then deleted automatically. Changes made before the activity
log was added to your store are not listed.
