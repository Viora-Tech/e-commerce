# Online store

## Themes

**Online Store → Themes** shows the look of your storefront. One theme is live at a time;
you can keep others ready to publish, and pick from presets or customise colours, fonts and
spacing.

## The editor

Open a page (or the theme) in the editor and you'll see a rail down the side with two tabs:

- **Sections** — the page's building blocks, top to bottom. Select **Add section** to add a
  new one anywhere in the order.
- **Theme** (or **Theme settings**) — colours, fonts and other store-wide look and feel.

### Apps tab and app blocks

When you're adding a section, there's also an **Apps** tab — sections that installed apps add
for you, for example:

- **Notify me** — a "back in stock" button shoppers can click on a sold-out product.
- **Pre-order countdown** — a launch countdown for a pre-order product.
- **Delivery checker** — lets a shopper type their PIN code and see an estimated delivery
  date, powered by whichever courier you've connected.

If you haven't installed any apps yet, this tab explains: "Apps you install can add things
like a 'Notify me' button or delivery-date checker here," with a link to browse apps.

## Saving and discarding

Changes in the editor aren't live until you save. The toolbar shows **Unsaved changes** while
you're editing, and **All changes saved** once you save. If you want to throw away your edits,
select **Discard**.

## Pages

**Online Store → Pages** lists every page built with the editor — title, URL, status and when
it was last updated. Select **Add page** to start a new one; each page also has its own
**Search engine listing** (title and description) and **Visibility**.
