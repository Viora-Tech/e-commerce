# Files and storage

**Content → Files** holds everything you have uploaded to the store: product photos, videos and
documents such as PDFs. Pictures you pick in the theme editor come from here too.

## What this is for

- Finding a picture you uploaded last month.
- Seeing how much space your files take.
- Finding the biggest files, so you can delete what you no longer need.
- Checking whether a picture is used on a product before you delete it.

## Browse and upload

**Where to find it:** **Content → Files**. **What you'll see:** a grid of tiles. Each tile shows
the picture, its name and its type and size, for example "JPG · 1.2 MB". Under the title a
summary says how many files you have and how much space they use, for example "86 files ·
2.1 GB used".

- **Tabs:** **All**, **Images**, **Videos** and **Documents**, each with how many files it holds.
  **Documents** is anything that is not a picture or a video, such as a PDF.
- **Search files** finds a file by name.
- **Upload files** opens your computer's files. You can also drag files onto the page. Each
  file shows its progress, then "1 file uploaded".
- Each tile says **Used on 2 products** or **Not used**. Deleting a file that is used removes it
  from those products' galleries straight away, so the delete box warns you first.

When a picture is added, it is resized and compressed for you. See
[Product photos and videos](/merchant-guide/products/photos-and-videos).

## Where your space goes

**Where to find it:** **Content → Files → Storage** (the **Storage** button on the Files page).
**What you'll see:**

- **Where your space goes**: a bar split into **Images**, **Videos** and **Documents**, with the
  space each one uses.
- **Largest files**: the biggest files first, with their type, size, when they were uploaded and
  how many products use them. A file marked **Not used** is a good one to delete. **View all
  files** goes back to the library.

Under these is the storage setting: where new uploads are kept (see [Apps](/merchant-guide/apps/app-store)
for Cloudflare R2 and Amazon S3). The page only shows what you have used. It does not show a
limit.

## Common problems and fixes

| Problem | Why it happens | Fix |
| --- | --- | --- |
| A picture is missing from a product after I deleted a file | The file was used on that product. | Upload it again and add it to the product. |
| The numbers on the Storage page lag | They are worked out when the page opens and after uploads and deletes. | Reload the page. |
| A PDF is not under **Images** | PDFs and other documents have their own tab. | Open **Documents**. |
