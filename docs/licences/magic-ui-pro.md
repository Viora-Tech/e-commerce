# Magic UI Pro: permission for use in the page builder

Magic UI ships a free (MIT) component set and a paid Pro tier. Using Pro-tier patterns as
editable blocks in our Puck editor, for every merchant on the platform, needed the same direct
confirmation as Aceternity UI Pro (`docs/licences/aceternity-pro.md`).

## Conditions we follow

Permission confirmed by the owner to Kuldeep Saini, 2026-09-26: "As long as the code is closed
source, you're good to go." Screenshot to be added by Kuldeep.

1. **Closed source.** Magic UI Pro code and patterns live only in this private repository. Never
   published, open-sourced, shipped as a downloadable theme, or exposed to merchants as source.
   If this repository or any package is ever made public, remove or replace the Pro code first.
2. **Rendered only.** Merchants place and configure the blocks in the editor; their storefronts
   receive the normal compiled bundle, as with any other component.
3. **Credit.** Blocks built from Magic UI Pro say so in the editor's block picker, with a link to
   https://magicui.design, and each adapted file carries a comment naming the source and this
   file, e.g. `Pattern after Magic UI Pro <X> (licensed; builder use permitted by the owner, see
   docs/licences/magic-ui-pro.md).`

This covers Magic UI (both the free MIT components and Pro) only. Free Magic UI components are
additionally covered under MIT in `THIRD_PARTY_NOTICES.md` / `packages/blocks/THIRD_PARTY_LICENSES.md`
regardless of this file, since MIT already permits that use.
