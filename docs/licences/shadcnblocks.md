# shadcnblocks: permission for use in the page builder

shadcnblocks' standard licence explicitly forbids using its blocks inside a website builder.
Using shadcnblocks-pattern sections as editable blocks in our Puck editor, for every merchant on
the platform, needed direct confirmation from the owner before we built anything, the same as
Aceternity UI Pro (`docs/licences/aceternity-pro.md`).

## Conditions we follow

Permission confirmed by the owner to Kuldeep Saini, 2026-09-26: "As long as the code is closed
source, you're good to go." Screenshot to be added by Kuldeep.

1. **Closed source.** shadcnblocks code and patterns live only in this private repository. Never
   published, open-sourced, shipped as a downloadable theme, or exposed to merchants as source.
   If this repository or any package is ever made public, remove or replace this code first.
2. **Rendered only.** Merchants place and configure the blocks in the editor; their storefronts
   receive the normal compiled bundle, as with any other component.
3. **Credit.** Blocks built from shadcnblocks say so in the editor's block picker, with a link to
   https://www.shadcnblocks.com, and each adapted file carries a comment naming the source and
   this file, e.g. `Pattern after shadcnblocks <X> (licensed; builder use permitted by the owner,
   see docs/licences/shadcnblocks.md).`

This covers shadcnblocks only.
