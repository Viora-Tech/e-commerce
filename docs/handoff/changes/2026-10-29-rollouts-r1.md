# Rollouts R1: Launch and Event rollouts (Markets → Rollouts)

Shopify's Markets → Rollouts: a set of store changes that goes live at a set time, for good
(**Launch**) or for a period that then rolls back or stays (**Event**, e.g. a Diwali sale).
Design (owner-approved): `docs/superpowers/specs/2026-10-28-rollouts-r1-design.md`.

- **Migration `0182_rollouts`** (renumbered from R1a's 0181 after dev's `0181_unlimited_store`):
  `rollout`, `rollout_change` with RLS, `stores_with_rollouts_due` (SECURITY DEFINER), and grants
  of the new `rollouts.read` / `rollouts.manage` permissions to existing roles (system admins and
  roles with `settings.manage` get both; roles with `settings.read` get read).
- **Core** `packages/core/src/rollouts/`: `schema.ts` (save schema, `RolloutError`), `views.ts`
  (list/get with change labels), `service.ts` (save, conflicts, start, pause, resume, end,
  archive, delete), `changes.ts` (apply/revert per kind), `targets.ts` (theme/discount pickers,
  `rolloutHolds` for the "In rollout" chips), `job.ts` (the tick).
- **Worker**: `{rollouts}-tick` every minute (`apps/worker/src/rollouts.ts`).
- **API**: `rollouts` router (`list`, `get`, `holds`, `listThemes`, `listDiscounts`,
  `checkConflicts`, `create`, `update`, `startNow`, `pause`, `resume`, `end`, `archive`,
  `delete`). MCP area `settings`; `end` and `delete` are sensitive (always approval).
- **Admin**: Settings → Rollouts (`/settings/markets/rollouts`, also linked from Markets): list
  with status filter; full-page create/edit with Add changes dialog (theme, checkout branding,
  discounts), "Edit theme for this rollout" (duplicates the live theme), schedule and end
  action, live conflict banner, Start now / Pause / Resume / End now / Archive / Delete.
  "In rollout: …" chips on the theme library, discounts list and Checkout → Branding.
  Copy in `data/rollouts.ts` + `data/hi/rollouts.ts`.
- **Docs**: merchant guide `settings/rollouts.mdx`; developer docs data model "Rollouts".

Not in R1 (per the design): catalog changes (wait for M3 catalogs), traffic %/experiments (R2).
`CheckoutBrandingSettings` now takes optional `onGstin` / `onOrderNotes` (hidden when left out).
