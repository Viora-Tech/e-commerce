# Inbox AI: knowledge base, brand voice, refund hand-off, Take over (2026-10-31)

Admin audit #134, #139, #178. The AI agent engine itself (worker job, hand-off, learn from past
replies) already existed; this adds what the audit asked for on top.

- **Knowledge base** (`inbox_knowledge`, migration `0198_inbox_knowledge`): title, answer,
  published, position, `source_metaobject_id`. Core `packages/core/src/inbox/knowledge.ts`
  (CRUD, reorder, counts, `bringOverImportedFacts`), pure rules in `knowledge-rules.ts`.
  API `inbox.knowledge.{list,create,update,setPublished,delete,reorder,bringOver}`.
  Admin page `/sales-channels/inbox/knowledge` (sidebar + inbox filters + AI agent settings link).
- **Bring over from Shopify**: finds the metaobject definition `shopify_knowledge_base_fact`
  (or named "Knowledge Base Facts"), copies each entry once. `value_*` answers keep Shopify's
  published flag; `suggested_value_*` (Shopify's guesses) come over unpublished.
- **AI agent prompt**: the published answers most related to the question
  (`pickKnowledge`, max 12 / 6000 chars) as STORE ANSWERS, and the new `ai.voice` setting as
  BRAND VOICE, both through `guardData`.
- **Refunds, returns, cancellations, exchanges** hand off without a model call
  (`asksForRefundOrCancel`, English, Hinglish, Hindi; policy questions still go to the AI).
- **Take over**: `inbox_conversation.ai_paused_at`; `inbox.takeOver`; `aiMayAnswer` respects it;
  `getConversation` returns `aiActive`, and the thread shows "The AI agent is answering this chat"
  with **Take over**.
- Not done: suggested question buttons in the storefront widget.
