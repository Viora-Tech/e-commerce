# Accent: Proofly blue is the default; Ocean Green is a real preset

`DEFAULT_ACCENT` was still the old kit's Ocean Green while the stylesheet's `--primary` became Proofly
blue (#3f72dc). Picking Ocean Green meant "no override", so the admin stayed blue. Now the default
(no override) is Proofly blue with the stylesheet's exact light/dark tokens, and Ocean Green is an
ordinary preset that overrides like the others. Settings › Appearance lists "Proofly blue" first.
