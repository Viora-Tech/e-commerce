# Orders › Drafts no longer answers 500

`/orders/drafts` failed on every load: "Attempted to call createParser() from the server but
createParser is on the client". The server page imports `draftViewInput` from
`lib/draft-list-filters.ts`, whose module-level `DRAFT_FILTER_PARAMS` builds a date parser
(`lib/date-filter.ts`) with `createParser` from the plain `nuqs` entry, a client module.

Both files now import from `nuqs/server`, which has the same parsers for code the server also
runs (the client hooks accept them unchanged). Found by the all-pages admin sweep (`docs/research/2026-11-admin-pages-perf.md`). Fixes #1404.
