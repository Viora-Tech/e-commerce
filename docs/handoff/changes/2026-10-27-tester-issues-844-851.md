# Tester issues #844–#851 (27 Oct)

- **#844 draft would not convert:** a draft's shipping address only counted with its own phone; the
  tester typed the phone in the Customer card, so the address was dropped on save and Convert stayed
  off with only a tooltip. `missingAddressParts` (drafts/draft-form-state.ts): the address phone falls
  back to the customer's phone; the hint names what is missing ("Shipping address still needs: Pincode").
- **#848 lowered coupon value "not registering":** not a bug. The order (15:57) used ₹10,000 before the
  value was lowered (15:58); orders keep the amount they got. The usage note now says so.
- **#849 unpaid online checkouts in All orders:** `paymentNotFinished` in order.service: a storefront
  checkout (cart id) with an online method never paid. Kept out of All / Unpaid / Unfulfilled /
  Cancelled; new tab "Payment not finished" (`payment_not_finished`). A search by number still finds it.
- **#850/#851 no save button:** Save at the top right of the product header (new product and edits);
  the bottom save bar stays.
- **#847 bulk edit cannot delete variants:** tick rows in the bulk sheet → "Delete N variants"
  (`products.removeVariants` → core `removeVariantsById`: archived when history points at them, else
  deleted; refuses to take a product's last variant). Editing option values in the sheet is not done.
- **#845 per-variant metafields:** already there ("Variant extra fields" card, pick a variant); renamed
  "Variant metafields: each variant has its own values" and "Manage metafields".
