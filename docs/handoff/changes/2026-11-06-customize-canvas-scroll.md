# Customize preview no longer slides up

Picking a section near the end of a page scrolled the admin box around the preview, which left an empty dark area at the bottom of the canvas. Only the page inside the preview scrolls now, and that box can no longer be scrolled by anything.

Fixes #1187.

The store switcher also marks the open store with a background and a tick. It used to be greyed out, so the other store looked picked.
