# Recent changes

One file per PR: `YYYY-MM-DD-short-title.md`, heading = what changed, then what a new session
needs to know (branch, migration, where the code lives, anything left undone).

**Every PR adds a new file here instead of editing `docs/handoff.md`.** New files never
conflict, so PRs built in parallel merge cleanly in any order. `docs/handoff.md` keeps only the
slow-moving parts: what this is, how to run it, enforced conventions, the queue.
