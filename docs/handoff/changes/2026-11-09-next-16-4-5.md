# Next.js 16.4.5 and React 19.3.1

Security upgrade, no code changes.

- `next` 16.4.2 → 16.4.5 in admin, storefront, docs, www and `packages/ui` (dev).
- `react` / `react-dom` ranges `^19.2.0` → `^19.3.1` everywhere; the lockfile now resolves 19.3.1
  (was 19.3.0). Peer ranges (`^19.0.0`) unchanged.

Why:

- Next.js 16.4.5 (3 Nov 2026) fixes seven medium advisories: GHSA-pc58-hwjq-p385 (cross-client
  response injection in self-hosted apps that forward fetched responses), GHSA-rhh4-g77r-r9qj,
  GHSA-vvgp-ww4w-46vf, GHSA-7qx7-33qx-rqx2 (SVG rejection bypass in image optimisation),
  GHSA-mfr8-8qww-v76h, GHSA-vc7v-qv4w-wrv8, and HttpOnly cookie exposure through an internal
  response header on Edge runtime routes.
- React 19.3.1 (14 Oct 2026) fixes GHSA-xqc2-xf4c-x3h3 (critical RSC remote code execution) and
  GHSA-h3gv-c5rc-p453. Next 16.4.1+ already patches its bundled copy, so this is defence in depth.

Deploy: rebuild the app images as usual. No migration.
