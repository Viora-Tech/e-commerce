# `bun run code-map`: what each file is for, without opening it

`scripts/code-map.ts`, run with `bun run code-map`:
- With no arguments: one line per app and package, with its file count and description.
- With a folder or words (`bun run code-map packages/core/src/seo`, `bun run code-map shipping checkout`):
  every matching source file, grouped by folder. Each line shows the file's purpose and its exports.
  - The purpose is the `SOURCE OF TRUTH:` header when the file has one, else the first sentence of its first doc comment.

It reads the files on each run, so it is never stale and adds nothing to commit or merge. CLAUDE.md now tells
agents to run it before searching. The goal is shorter start-up for helpers, which spent much of their
time locating files.

**Keep it useful:** start every new file with a one-sentence doc comment saying what it is for. Core files
keep the `SOURCE OF TRUTH:` header the sweep requires.
