# GST invoices app: preview draws on the live admin, Queue empty state, one "All documents"

Branch `fix/gst-app-ux`. No migration.

- **Settings preview ("The preview could not be drawn").** The live preview renders in the
  browser with react-pdf and loads its fonts from `/api/apps/gst-invoices/fonts/*`. That route
  reads `packages/invoices/fonts` by path (`fontsDir()` in `@commerce/invoices/render`), which
  Next's standalone tracing never copies, so in the Docker image the route throws (500), the
  font load fails and react-pdf rejects the whole render, whatever the settings hold. Fix: the
  fonts join the PIN code directory in `outputFileTracingIncludes`, now one list in
  `apps/admin/src/lib/traced-files.ts` (read by `next.config.ts`). `traced-files.test.ts` fails
  if a font `FONT_FILES` names is not covered. `packages/invoices/test/preview-render.test.ts`
  renders every document kind from partial settings (blank seller, legal name only, empty HSN,
  A5 compact, no logo or signature) to pin that the templates themselves draw.
  Confirm after deploy: Apps › GST invoices › Settings shows the PDF, and
  `/api/apps/gst-invoices/fonts/inter/Inter-Regular.ttf` returns 200.
- **Queue empty state.** `components/apps/gst-invoices/queue-empty.tsx` replaces the one-line
  table row: what the queue holds, when orders join (follows the "Queue orders" setting), how
  to add one by number, and links to Settings and Orders. With a date range set it asks to
  clear the dates instead. Copy: `gstQueueEmptyContent` in `data/gst-invoices.ts`, Hindi in
  `data/hi/gst-invoices.ts`. The old `queue.empty` string is gone.
- **"All documents" twice.** The Invoices list type filter labelled its select "All documents"
  and its default option said the same. The label is now "Document type", screen-reader only
  (`ChoiceField` `hideLabel`), like the date filters beside it.
