# CodeBuild builds x86 images

- `deploy/codebuild/*` and the CodeBuild docs page now target x86 (`LINUX_CONTAINER`,
  `amazonlinux-x86_64-standard:5.0`, `BUILD_GENERAL1_LARGE`) instead of ARM.
- Why: production moves from the t4g (ARM) box to an x86 app server (t3a.medium, Mumbai) managed by
  the Dokploy panel on Hetzner; OpenMausBot also needs x86. Images must match the server.
- ECR repos `vextro/worker`, `vextro/admin`, `vextro/storefront` exist (ap-south-1). The IAM role,
  GitHub connection, CodeBuild project and nightly rule are not created yet.
