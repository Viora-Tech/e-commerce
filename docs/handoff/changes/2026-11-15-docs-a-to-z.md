## Diagrams (Excalidraw)

- Eight diagrams in `apps/docs/public/diagrams/`: `system-overview`, `stores-and-tenancy`,
  `app-lifecycle`, `order-lifecycle`, `theme-system`, `release-and-deploy`, `ai-and-mcp`,
  `data-model`. Each is an editable `.excalidraw` file plus `.svg` (light) and `.dark.svg` (dark).
- `apps/docs/scripts/render-diagrams.mjs` (`bun run --cwd apps/docs diagrams`) draws the SVGs from
  the `.excalidraw` files with Rough.js (MIT, new docs dev dependency, the library Excalidraw draws
  with); the dark file applies Excalidraw's own dark filter to every colour. Credited in
  `THIRD_PARTY_NOTICES.md`.
- `<Diagram name alt caption />` (`apps/docs/components/diagram.tsx`, copy in `data/guides.ts`):
  shows the right SVG per theme, opens full size, links the `.excalidraw` file with "open it in
  excalidraw.com to edit". Documented in `apps/docs/README.md`.
- To edit: open the `.excalidraw` on excalidraw.com, save it back, run the script, commit all three.
