# AI engine, "Write with AI" and "Ask your store"

**Branch** `feat/ai-engine` from `main`. **Migration `0083_ai_engine`** (number reserved: 0081 is
the theme import build, 0082 the GST build; if either lands later, re-check the journal order):
tables `ai_settings` and `ai_usage`, per store, `apply_store_rls()`.

- **Engine** `packages/ai` (`@commerce/ai`, server only; `@commerce/ai/client` is client-safe,
  `@commerce/ai/testing` has mock models). Vercel AI SDK 7 (Apache-2.0) behind our own
  interface: `generateStructured`, `streamAnswer`, `defineAiTool` (`risk: 'write'` tools go to
  the SDK's tool approval and never run on their own). Provider by env: `AI_GATEWAY_API_KEY`
  (Vercel AI Gateway) or `OPENROUTER_API_KEY`; `AI_PROVIDER` (`gateway|openrouter|mock|off`),
  `AI_MODEL` override, `AI_UNLIMITED_STORES` (slugs). No key = AI off, buttons hidden. `mock`
  is a built-in fake model for local demos, refused in production. Models per feature in
  `packages/ai/src/features.ts` (Claude Haiku 4.5 by default); plans and quotas in `plans.ts`.
- **Gate** `packages/api/src/services/ai/guard.ts`: configured → 20 calls / 5 min per store
  (shared rate-limit store) → feature switch → monthly quota (IST month) → count the call; tokens
  added after (`onUsage` also on an aborted stream). New `canDetached(permission)` in
  `procedures/store.ts`: access checked in a short transaction, handler runs outside one (model
  calls and streams must not hold a connection idle in a transaction). `can`/`storeProcedure`
  share the same helpers and behave exactly as before.
- **Router** `ai`: `status` (bare `storeProcedure`, self-scoped booleans, documented in the
  guardrails router idiom), `settings` (settings.read), `saveSettings` (settings.manage),
  `writeProduct` (products.write), `ask` (analytics.read, oRPC event iterator stream).
  `ai.writeProduct` and `ai.ask` are in the cross-store leak test's SKIP list (model provider).
- **Write with AI**: product page, Basic details card. Photos (640px WebP variant when present,
  max 3) read from the store's own storage under RLS; output zod schema
  `packages/ai/src/product-writer/schema.ts`, clamped. Preview now vs suggested with ticks;
  Apply patches the form (`apps/admin/src/lib/ai-product-copy.ts`), never saves.
- **Ask your store**: Home, under the briefing. Read-only tools in
  `packages/api/src/services/ai/store-tools.ts` (sales summary, top products, low stock, pending
  orders, abandoned checkouts) return formatted `facts`; no customer PII. Answers stream in;
  "Show the data used" lists the facts. Answers in Hindi when the admin is in Hindi.
- **Settings → AI** (`/settings/ai`): usage this month vs quota, per-feature switches, data note.
  Copy `apps/admin/src/data/ai.ts` + `data/hi/ai.ts`. New icon `AiIcon` in `packages/ui/icons`.
- Small refactor: `variantKey` moved to `packages/core/src/media/constants.ts` (no `sharp`
  import for the admin), re-exported from `pipeline.ts` as before.
- **Docs**: developer docs Building → AI engine (how to add a feature as one slice), merchant
  guide Settings → AI features, open-source radar row, THIRD_PARTY_NOTICES paragraph.
- **Next**: store assistant agent with approvals (write tools: draft a discount, restock note,
  mark shipped, each confirmed by the merchant through the approval event), smart storefront
  search (embeddings), more writers (collections, blog, emails).
