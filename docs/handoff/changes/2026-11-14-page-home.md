# Home page pass (design audit section 7, page pass 5)

Branch `design/page-home` from 6e54fc581. Route: `/` (Home).

## What was still off

1. Latest orders, Live now and Store health were hand-made `surface-card` panels; the first two
   had their title outside the card (SectionHead above a bare panel), Store health had a small
   `text-body font-semibold` title.
2. The sales hero used `rounded-xl` (1rem) next to 0.75rem cards.
3. Card and tile titles in three styles: `text-base leading-5 font-semibold` (to-do tiles, More
   numbers), `text-body font-semibold` (Store health), `text-card-title` elsewhere.
4. SalesMetricTiles wrote its figure as `text-2xl leading-[1.8125rem] font-semibold
   tracking-[-0.03rem]` and its change line as `text-xs`, off the stat tokens.
5. Latest orders' hover buttons were links styled by hand (`rounded-[0.4375rem]`, `py-1.25`).
6. A failed range change on the hero only showed a toast.
7. The loading picture (`layout/dashboard-skeleton.tsx`) no longer matched the page: a 2fr:1fr
   split (real 640fr:424fr), a 26rem block for a ~27.5rem hero, a set-up row that most stores
   never see, no Store health, no section headings, Ask AI without its question chips, 4 x 7rem
   suggestion blocks (real 7.75rem), no More numbers row.

## What changed

- New `components/home/home-layout.ts`: Home's layout classes (rhythm, 48rem column, 640:424
  split, hero shell/toolbar/tiles/chart/footer, tile box and type, to-do and suggestion grids,
  order row, globe height). The page and the skeleton both read them, so they cannot drift.
- Latest orders, Live now and Store health are DataCards (title inside, `text-card-title`,
  0.75rem corners). Latest orders' "View all" is the card action, rows run edge to edge; Live
  now's globe sits flush at the card foot; Store health's Open button is the card action.
- Sales hero on the one card radius (`rounded-lg`). A failed range/compare change now shows an
  inline error with Try again over the last figures (the tile-save failure keeps its toast).
- SalesMetricTiles on tokens: label `text-caption`, figure the new `text-stat-md` token
  (1.5rem/1.8125rem/600/-0.02em, exactly the old look), change and note lines `text-period`.
- To-do tile titles and the More numbers title use `text-card-title`; the "all caught up" panel
  is the ui Card instead of a hand-made div.
- Latest orders' Ship and View are `buttonVariants` xs (default and outline).
- The Home skeleton is rebuilt from the real boxes (see the component comment). Finish setup is
  left out of it on purpose: it renders only while a set-up step is open.

Every number, range switch, compare menu, channel menu, Customize, link and the gap-10 rhythm
are unchanged.

## Shared files touched

- `packages/ui/src/styles.css`: new `--text-stat-md` token (additive).
- `packages/ui/src/lib/utils.ts`: `stat-md` added to the tailwind-merge font-size list.
- `components/layout/dashboard-skeleton.tsx`: only used by the root `loading.tsx` (Home).

## Tests

`components/layout/dashboard-skeleton.test.tsx`: the skeleton uses Home's page frame, the 48rem
column, the hero shell, the 640:424 split, four tile boxes and five order rows, and the loaded
SalesMetricTiles share the same tile grid, box and figure token.
