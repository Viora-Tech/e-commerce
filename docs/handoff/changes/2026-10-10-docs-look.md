# Docs: the admin's Proofly look

- Fonts: DM Sans for text and Bricolage Grotesque for headings, loaded like `apps/admin/src/app/layout.tsx`; Geist Mono stays for code.
- Colours: the admin's single blue and neutral tokens (light and dark, from `packages/ui/src/styles.css`) in `apps/docs/app/globals.css`, Nextra's primary hue and page backgrounds in `app/layout.tsx`, and the Mermaid theme in `lib/mermaid-config.ts`.
- Rounded cards with hairline borders, a soft-blue active sidebar item, section icons (Phosphor, matching the admin sidebar), rounded frames around images and screenshots, numbered Steps with soft-blue circles.
- Home page: large search, "I want to..." task cards (`taskCards` in `data/home.ts`), browse by audience.
- New `<Find where todo see />` component for the "Where to find it, What to do, What you'll see" pattern (registered in `mdx-components.tsx`). Existing pages were not rewritten to use it.
- Brand name now comes from `siteConfig.brand.name`.

How to test: open http://localhost:3500 in light and dark, check the home page, the sidebar icons and active state, a page with Steps, a page with a diagram, and the search box.
