# Puck 0.24.1 upgrade (20 Nov 2026)

Branch `chore/puck-0-24` (from `dev`). `@puckeditor/core` `^0.23.0` → `^0.24.1` in
`apps/admin`, `apps/storefront`, `apps/storefront-hono` and `packages/blocks`; `bun.lock` updated.
Puck's own upgrade guide says 0.24 has no breaking changes; one change did break us.

## What broke, and the fix

- **`fields` override `children`**: since 0.24 Puck passes `children` as ONE element (its own
  layout, `ComponentFields`), not one keyed element per field. `InspectorFields` split
  `children` by key to build the Basic / Advanced tabs and the `data-inspector-field` marks a
  canvas click scrolls to, so both would have stopped working silently (every field in the
  Content card, canvas click-to-field doing nothing). It now reads the new `fields` prop
  (field name → rendered field): `inspector-fields.tsx`, `customize-overrides.tsx`, and its test.

## Checked, no change needed

- `fieldTypes` overrides may now be `null` (hides that type): we set none to null;
  `withDynamicSources` and the overrides typecheck as they are.
- Object field `variant` (default `card`): `card` is the same bordered box 0.23 drew, and we
  override `object` entirely (`customize-object-field.tsx`, `video-setting-field.tsx`), so
  Puck's object field never renders. No `variant` added (`flush` would change the look).
- `actionBar` gets `dragHandle` / `dragHandleRef`: only when `dnd.enableDragHandle` is set; we
  don't set it.
- Backspace from inputs no longer captured by Puck: our capture-phase Delete/Backspace in
  `customize-hotkeys.tsx` already skips inputs, textareas and contenteditable.
- `resolveAllData` resolves each node once (was twice for slot children): every `resolveData`
  in `packages/blocks` is a pure `({ props })` load or idempotent rewrite, so this only halves
  the loader calls in `template-render.tsx`, `product-page.ts` and the section-preview script.
- Inline text placeholders on the canvas: only drawn when a field sets `placeholder`; none of
  our `contentEditable` fields (`sections/inline-fields.ts`) do.
- New field type `checkbox` has no admin override; nothing uses it yet. Add one before using it.
- 0.24.1 adds an experimental `@puckeditor/cli` dependency (canary build) to the lockfile.

## Verified

Typecheck admin, storefront, storefront-hono, blocks: clean. Tests: admin
`components/themes/customize` 100/100 and `lib/customize*` 107/107, blocks 763/763,
storefront 641 (1 skipped), storefront-hono 8/8. Not run on a dev server.

## To click through in the theme editor

Select a section with settings: Basic shows only content fields in one Content card, Advanced
shows Layout / Spacing / Style / Advanced cards. Click a heading or image on the canvas: the
inspector scrolls to and rings that field. Edit a link, an image, a video and a collapsible
object group. Select a block and press Delete (collapse animation), then type Backspace in a
text field (only the text changes). Preview and publish a page with a product card element.
