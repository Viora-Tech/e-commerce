# RapidShyp and Reviews marked tested

The owner confirmed on 17 Nov which apps were run end to end on a live store. RapidShyp and Reviews
now set `tested: true` in their plugin definitions, so the admin's App Store and Installed apps no
longer show the "Untested" badge on them. Razorpay, Delhivery, Cloudflare R2, Shopify importer and
GST invoices already had it. The owner is going through the remaining apps; each one they confirm
gets the same one-line change.
