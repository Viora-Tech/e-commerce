# Trade name in the Add GST number dialog

A proprietor's GST certificate has two names: Legal Name (the owner, as on PAN) and Trade Name
(e.g. "VIORA INDIA"). The Add GST number dialog only asked for the legal name, and the first GST
number created the business with no trade name. The dialog now has a Trade name field; it is saved on
the registration and, for the store's first business, on the business too.
