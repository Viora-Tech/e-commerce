# Checkout: cleaner on a dark imported theme

- The dark checkout shows the theme's logo for dark backgrounds (`liquidThemeDarkLogoUrl`).
- No section boxes in dark mode: the page reads as one column.
- `CheckoutMoney` clears the store's price format inside the checkout, so every amount uses the
  rupee sign. A market abroad still shows its own currency.
- Payment rows read "Razorpay Secure" with UPI, Visa, Mastercard and RuPay marks on the right.
  Manual methods read "UPI ID" and "Bank deposit".
- The pre-order note runs the full width of the summary.
