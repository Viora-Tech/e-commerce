# Koomerce pricing (decided 2026-10-18)

Prices exclude 18% GST. No free plan: every new store gets a 14-day trial at Growth level, no card needed.

## Plans

| | Starter | Growth | Pro |
|---|---|---|---|
| Monthly | ₹499 | ₹1,499 | ₹4,999 |
| Yearly (2 months free) | ₹4,990 | ₹14,990 | ₹49,990 |
| Orders / month | 50 | 200 | 1,000 |
| Staff | 2 | 5 | 15 |
| AI credits / month | 500 | 3,000 | 15,000 |
| Storage | 2 GB | 10 GB | 50 GB |
| Custom domain, GST invoices, couriers, payments, Hindi admin | yes | yes | yes |
| Shopify theme import | no | yes | yes |
| Included apps | Core only | + Reviews, Back in stock, Forms | All first-party apps |
| MCP & API, multiple locations | no | no | yes |
| Support | Email | Email + WhatsApp | Priority |

- Orders over the limit are never blocked. Over the limit: prompt to upgrade; on Pro, recommend the Own it license.
- Overage: ₹49 per extra 100 orders (until they upgrade).
- Paid apps on Starter/Growth: bought per app (₹99–299/month each). Included on Pro.
- Third-party apps (later): always paid separately; hosted by the app developer.

## Metered on every plan

- **AI credits**: metered by real tokens (input and output weighted by model price), shown to merchants as credits. 1 credit = ₹0.10 of model cost. Top-up: ₹199 per 1,000 credits.
- **WhatsApp**: separate plugin, prepaid wallet, Meta's rate + ~20%.

## Own it (license) — for unlimited orders

- ₹49,999 one-time (~$500). One brand per license; not resold or sublicensed; no competing SaaS.
- The brand hosts it on its own server and runs it.
- Maintenance ₹3,000/month, 12-month minimum: updates, security and bug fixes, help applying updates, email/WhatsApp support within 48 h.
- Not included: feature requests (quoted per request), problems from their own code changes or their server.
- Optional setup on their server: ₹7,500 one-time.
- Includes core and the apps that exist at purchase; paid apps released later cost extra.
- Pitch against Shopify Grow (~₹6,700/month + apps + transaction fees).
